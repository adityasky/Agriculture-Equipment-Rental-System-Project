# KrishiKart - Frontend

This is the frontend of the KrishiKart Agriculture Equipment Rental System.

## Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- Axios
- React Router
- Tailwind CSS

## Features

- User Registration and Login
- Farmer Dashboard
- Machinery Browsing
- Machinery Booking
- Booking Management
- Payment Integration
- Invoice Management
- Responsive User Interface
- API Integration with ASP.NET Core Backend

## Project Structure

- `src` - Main application source code
- `public` - Public/static files
- `package.json` - Project dependencies and scripts

## How to Run

1. Install Node.js.
2. Open the frontend project folder.
3. Install dependencies:

```bash
npm install
