# 🌾 KrishiKart - Agriculture Equipment Rental System

KrishiKart is a full-stack web application designed to make agricultural equipment easily accessible to farmers through an online rental platform.

The system allows farmers to browse available agricultural machinery, book equipment for specific periods, make payments, and manage their bookings. Equipment owners can list their machinery and manage rental requests.

## 🎯 Project Objective

The main objective of KrishiKart is to provide a convenient platform that connects farmers with agricultural equipment owners, reducing the need for farmers to purchase expensive machinery for occasional use.

## 🚀 Key Features

- User Registration and Login
- JWT-based Authentication
- Browse and Search Agricultural Equipment
- Equipment Details and Availability
- Equipment Booking and Rental Management
- Owner Equipment Management
- Booking Management
- Maintenance Management
- Invoice Generation
- Online Payment Integration
- RESTful API Architecture
- SQL Server Database
- Responsive Web Interface
